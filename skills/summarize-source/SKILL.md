# Summarize source

実行前に [Skill setup](../../docs/workflow.md#skill-setup) を読み、利用環境に合わせて実行手段と依存機能を確認する。

指定ソースだけから、そのソースが述べる内容と述べない内容を明確にして要約する。`grill-federated` は使わず、指定外ソースを探さない。

## 手順

1. ソースと、指定されていれば注目箇所を確認する。アクセス不能な場合だけ必要事項を聞く
2. 連合検索で関連する既存記事の**存在だけ**確認し、あればユーザへ知らせる。既存記事の内容を要約へ混ぜない
3. 指定ソースを読み、バージョン識別子・取得日・ページやcommit等の範囲を控える
4. ソースの中心的な主張・構造・根拠・前提・限界を、必要な粒度でまとめる
5. 原典の明言、そこから直接導けること、ソースが答えていないことを分ける

## 終了

ユーザから直接呼ばれた最上位ワークフローなら、取得日・バージョン・指定範囲と整理済みの理解を `write-article` へ渡し、指定ソースだけに基づく自己完結した記事候補をknowledge repo直下の `./drafts/` に作る。生の箇条書き要約をそのまま保存せず、指定外ソース・既存記事・モデル知識を本文へ混ぜない。既存記事で十分ならドラフトを作らず、その記事を提示する。

- 指定外ソースも調べたい → `survey`
- 今後従う用語・判断にしたい → `distill`

`study-book` など別の情報理解ワークフローから内部利用された場合は、要約だけを呼出元へ返し、重複ドラフトを作らない。

ソースが答えていない点をモデル知識で補強せず、不足として残す。
