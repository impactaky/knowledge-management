# Knowledge management Catalog

This Catalog is the local entrance for work in this repository. Resolve its
relative paths against this directory. `examples/minimal/CATALOG.md` is a separate
synthetic store used for demonstrations and tests.

Read file entrances directly and choose relevant documents within directory
entrances. Follow explicit required references; an INDEX is not automatically
required for a directory. Search finds candidates; read the originals before
reusing their claims.

For articles authored here, create drafts in `drafts/` and present the complete
destination `articles/<theme>/<slug>.md` before stock approval. Keep personal and
organizational knowledge in a separately selected store. Do not infer a write
destination from another connected Catalog or from neighboring directories.

## Packages

- [memory-foundation](foundation/INDEX.md) — Read when working on knowledge-management mechanisms, their vocabulary or adoption rules.
- [articles](articles/) — Reviewed articles authored for this repository; use for article reuse and approved stock operations here.
