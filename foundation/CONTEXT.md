# Knowledge management

**Knowledge store**: A user's originals, separated from reusable tooling and from
other stores according to who may read them.

**Knowledge package**: A named file or directory entrance selected through a
Catalog, with stated applicability. It need not have an INDEX.

**Catalog**: The authoritative package entrance list and reading instructions.

**Claim**: An authored, scoped statement in an article's opening frontmatter,
used to decide whether to read that original. Retrieval does not prove a claim.

**Derived index**: Disposable search state. Rebuild it from originals; never edit
it as the canonical knowledge.

See [article curation](modules/article-curation/CONTEXT.md) for adoption terms.
